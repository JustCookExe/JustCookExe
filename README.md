<h3 align="center">Small tools, sharp edges, no drama.</h3>

Most of what I ship is React and Next.js, usually Tailwind and Vite alongside, and I end up spending more time on the parts nobody notices — bundle size, focus order, the small jank on scroll. I like design systems that hold up once real content lands in them, and interfaces that stay usable when the network doesn't cooperate.
